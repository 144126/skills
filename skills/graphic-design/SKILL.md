# Graphic design

Research this skill came from — read it first: [references/graphic-design-first-principles.md](references/graphic-design-first-principles.md) (color and shape depth: [references/aesthetics-motion-color-shape.md](references/aesthetics-motion-color-shape.md))

The eye is a compressor tuned to nature: it enjoys structure it can code cheaply, plus one surprise it can resolve. Beauty buys trust; memory needs a meaningful, distinct anchor.

Order
- Few elements. Too busy hurts far more than too plain.
- Group by spacing ratio: gaps inside a group clearly smaller than gaps between groups. A shared panel groups hardest.
- Align to a grid. Use symmetry, or balance around the center.
- Look typical for the category, then add one twist.

Hierarchy
- Rank by position and size first; color saturation and shading are read worst.
- One subject: center it. If it faces sideways, give it room ahead.
- Eyes go to faces, then text. A face looking at the message pulls eyes there; a face staring out steals them.
- Lead headings, lines, and bullets with the information-carrying words.

Type
- Contrast at least 4.5:1 (3:1 for large text). Clear text is believed more.
- Lines about 50-70 characters, real margins, body x-height in the fluent range (about 4-40 pt at arm's length).
- The font must fit the message: fit doubled brand choice.
- Never use hard-to-read type to aid memory. It does not.

Color and shape
- 2-3 neighboring hues, spread from light to dark, one contrasting hue for the focal element. Avoid mostly dark.
- Curves read safe and friendly; sharp points read tense.

Memory
- Add a person, a face, or a recognizable object.
- Make exactly one element differ from everything around it.
- Logos: natural (representational, organic) with repeated parts.

Check: view it thumbnail-size for a split second. Calm, clear, and obviously what it is? Does the one focal element win?
